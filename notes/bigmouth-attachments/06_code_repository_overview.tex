\section*{Quick orientation}

The DentaCoPilot codebase implements every model evaluated in the
manuscript, the synthetic chart generator that produced the corpus, and
the audit / replay infrastructure that makes the run records reviewable.

\section*{How a reviewer can audit our work in 30 minutes}

\begin{enumerate}
    \item Clone the repository.
    \item \texttt{cd 07-dental-procedure-prediction \&\& make smoke}
    runs the full Stage-1 pipeline (CDT vocabulary $\to$ synthetic chart
    generation $\to$ B0/B1/B2 baselines $\to$ figures) end-to-end without
    spending any Claude Code quota.
    \item Inspect any \texttt{data/results\_<run>/llm\_calls.jsonl} ---
    every LLM call is logged with full prompt, full response, latency,
    and token counts. The reviewer can read the model's reasoning on any
    individual case without re-running anything.
    \item \texttt{make verify} runs the no-anthropic-SDK CI check
    (the grep guard ensuring no metered API path can be introduced).
\end{enumerate}

\section*{Reproducibility primitives}

\begin{itemize}\itemsep0pt
    \item \textbf{Seeds}: \texttt{random.seed(42)},
    \texttt{numpy.random.seed(42)}, \texttt{torch.manual\_seed(42)} at the
    top of every script.
    \item \textbf{Run records}: \texttt{config.json} (git SHA + seed +
    CLI args + Python version + platform), \texttt{results.json}
    (per-trial predictions), \texttt{summary.json} (aggregated metrics),
    \texttt{llm\_calls.jsonl} (every LLM call).
    \item \textbf{Determinism}: re-running a baseline with the same seed
    produces byte-identical \texttt{summary.json}; LLM models reproduce
    within stochastic tolerance documented in the manuscript.
\end{itemize}

\section*{Compute substrate}

A central design choice: every LLM inference call goes through the local
Anthropic Claude Code CLI rather than the metered Anthropic API. The
single subprocess wrapper at \texttt{data/cc\_compute.py} invokes
\texttt{claude -p ...\ --output-format json} and parses the structured
response. The full call record is logged to a per-run JSONL audit
trail.

\section*{What we will share with BigMouth}

\begin{itemize}\itemsep0pt
    \item Read access to the live private repository for the BigMouth
    project review committee, on request.
    \item A short live walk-through (videoconference) of any module the
    committee wants to inspect, on request.
    \item Public open-source release on the project's accepted-paper
    publication date; MIT licence; no patient data in the repository.
\end{itemize}
